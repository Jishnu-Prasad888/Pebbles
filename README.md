# usage :

1. navigate to your vault then go to .obsidian/themes
2. create a new folder called pebbles or whatever you want to name it
3. download the manifest , theme and the script file and place in the pebbles folder
4. download a image you want to use in png format and place it in the same folder and rename it to pic.png
5. run the script
6. open obsidian and set the theme to pebbles or what you named it
